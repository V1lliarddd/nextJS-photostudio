- **CSS Modules**
- **GSAP**

### Установка и запуск

1. **Склонировать репозиторий**

```
git clone https://github.com/yourusername/photostudio.git
cd photostudio
Install dependencies

npm install
# or
yarn install
# or
pnpm install
```

2. **Запустить dev сервер**

```
npm run dev
# or
yarn dev
# or
pnpm dev

Open http://localhost:3000 in your browser
```
